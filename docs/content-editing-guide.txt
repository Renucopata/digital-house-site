CONTENT EDITING GUIDE — where to change each piece of text and data on the website
Date: 2026-10-14   (line numbers are from this date; if they shift, search for the quoted text)

==========================================================================================
0. BEFORE YOU START
==========================================================================================
- All the website text lives in 4 files inside src/content/. You never need to touch the
  components (src/components/) to change text.
      src/content/contact.ts      WhatsApp number, WhatsApp message, email, Instagram
      src/content/site.ts         brand name, website address, slogan lines, footer labels
      src/content/navigation.ts   menu links and menu button texts
      src/content/home.ts         ALL the text of the page sections (hero → contacto)
- Only change what is INSIDE the quotes "...". Keep the quotes, the commas at the end of
  lines, the brackets [ ] and braces { } exactly as they are.
- If your text contains a double quote ", write it as \" (or use « » instead).
- Write in Spanish with "tú" (trabajas, quieres), not "vos" — project rule D12.
- Never publish anything from the confidential list in CLAUDE.md §5.
- After any change, check it locally and then publish:
      npm run dev        → open http://localhost:3000 and look at the change
      npm run build      → must finish without errors
      git add . ; git commit -m "Update content" ; git push   → Vercel publishes it
