  "GROWTH STUDIO" (tracked label):
    League Spartan 400 @0.40em 0.60 · Poppins 400 @0.35em 0.46 · Outfit 300 @0.35em 0.44 ·
    Poppins 300 0.41 · Lexend 300 0.33 · Montserrat 400 0.32
    (20 px tall text in a JPEG → low-confidence; Poppins 400 is visually equivalent and keeps
    the family count down.) Tracking ≈ 0.35–0.40em confirmed.

  "Más estrategia." (Ctrl+N post headline):
    Poppins Medium/SemiBold 0.73 · Poppins 700 0.68 · League Spartan 0.63 · Lexend 0.62 ·
    Montserrat 0.61 · Outfit 0.59  → the post copy is Poppins.

  "digital" (didone serif):
    NO close free match. The logo is a CONDENSED high-contrast didone with very tall ascenders
    and a binocular "g"; every free candidate is 1.3–1.8x wider:
    Prata 0.26 w1.64 · Libre Bodoni 0.25 w1.57 · Cormorant Garamond 0.25 w1.46 ·
    Bodoni Moda 0.23 w1.63–1.67 · Playfair Display 0.21 w1.71 · Instrument Serif 0.21 w1.34 ·
    Italiana 0.20 · Gloock 0.19 · Noto Serif Display (wdth 62) 0.18 w1.33–1.43 · Kalnia ≤0.16
    Likely a commercial font (official files = P5). Because the logo is always an image (D8),
    the headline serif only needs to be in the same family, not identical.

  Recommendation (to approve in P5):
    Display serif  → Bodoni Moda (true didone: vertical stress, hairlines, binocular g;
                     opsz axis); alternative: Playfair Display. Prata scores slightly higher
                     numerically but reads heavier/wedge-like, less like the logo.
    Sans (all)     → Poppins: 800 strong headlines / "HOUSE"-style, 500–600 headline lines,
                     400 body, 400 UPPERCASE @0.35em labels. One family = matches brand.
    Handwritten    → SVG hand-drawn assets (CLAUDE.md §4.3); no font needed.
