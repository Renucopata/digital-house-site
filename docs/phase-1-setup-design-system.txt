4. SECTIONS / COMPONENTS
==========================================================================================
Layout (src/components/layout)
  Container      props: width "default" (max 72rem) | "narrow" (44rem), className.
                 Side gutters = --gutter (20px → 40px fluid).
  Section        props: id, theme "light" | "sand" | "dark", grain (bool), windowShadow
                 (bool | "left" | "right"), flush (no vertical padding), as ("section" | "div" |
                 "footer"), className, aria-labelledby. Vertical padding --section-space
                 (72px → 136px fluid). Adds scroll-mt-24 when it has an id (header offset).
  WindowShadow   SVG window mullions + leafy branch, CSS-blurred 12px, 7% opacity, ink follows
                 --texture-ink. props: side, className. Used inside Section.
  WhatsAppFloat  fixed bottom-right, 56px burgundy circle, cream WhatsApp glyph, cream ring
                 (visible on dark sections), z-index 1000, safe-area aware, aria-label
                 "Escríbenos por WhatsApp", opens contact.whatsappUrl in a new tab
                 (rel="noopener noreferrer"). Mounted globally in Phase 2; in Phase 1 only on
                 /styleguide.
UI (src/components/ui)
  Button         pill. props: variant "filled" | "outline", size "md" (44px min height) |
                 "lg" (52px), icon, href (renders <a>), external (new tab + rel), aria-label;
                 without href renders <button type="button|submit"> with onClick.
                 Theme-aware (ivory pill with burgundy text on dark sections).
  Eyebrow        uppercase label, 12px, Poppins 400, tracking 0.35em, accent color.
                 props: as "p" | "span" | "div", className.
  SectionHeading props: eyebrow, title (ReactNode), lead, level h1|h2|h3, font "serif"
                 (Bodoni Moda; <em> = italic, <strong> = accent) | "sans" (Poppins; <strong> =
                 semibold accent — the Ctrl+N headline pattern), size display|h1|h2|h3,
                 align left|center.
  HandUnderline  wraps a phrase; double marker swoosh under it (SVG, non-scaling 2.25px pen).
  HandArrow      looping arrow pointing right (flip with -scale-x-100).
  Sparkle        4-point outline star ✦. props: className (size), strokeWidth.
  InstagramPill  "SÍGUENOS EN" + outlined pill: IG glyph │ divider │ @digitalhouse.gs; links to
                 instagram.com/digitalhouse.gs (new tab). props: label (bool), className.
  Logo           next/image wrapper. props: variant "wordmark-burgundy" | "wordmark-cream" |
                 "monogram" | "monogram-cream", width (CSS px), priority, className.
                 Max sharp width: wordmarks 318px, monogram 297px (sources are 2x).
  icons          WhatsAppIcon, InstagramIcon (Simple Icons paths, CC0).

5. STYLES
==========================================================================================
Colors (src/styles/tokens.css → Tailwind classes via @theme inline)
  burgundy #670812 · burgundy-deep #51020C · cream #F8F4E9 · ivory #F3EBE0 · sand #EFE6DC ·
  sand-deep #E7D8CA · ink #481F1E · ink-soft #6B5552        → bg-*/text-*/border-* utilities
  Semantic (per theme): surface, fg, fg-soft, accent, on-accent, line
    light: cream / ink / ink-soft / burgundy / cream / burgundy 40%
    sand : sand  / ink / ink-soft / burgundy / cream / burgundy 45%
    dark : burgundy-deep / ivory / ivory 80% / ivory / burgundy-deep / ivory 40%
  Contrast (WCAG): all text pairs ≥ 4.95:1 (see phase-0 §5.3); fg-soft on dark ≈ 9:1.
Fonts (next/font/google, self-hosted at build, display: swap)
  Bodoni Moda — variable wght + opsz axis, normal + italic → --font-bodoni → font-serif
  Poppins — 400, 500, 600, 800 → --font-poppins → font-sans (default body font)
  Fallbacks: "Bodoni 72", Didot, Georgia, serif / ui-sans-serif, system-ui, sans-serif
Type scale (fluid clamp, Tailwind text-* classes)
  text-display 48 → 104px / 1.0 · text-h1 40 → 76px / 1.04 · text-h2 32 → 52px / 1.1 ·
  text-h3 20 → 24px / 1.3 · text-lead 17 → 20px / 1.65 · body 16px / 1.7 · text-label 12px / 1.4
  tracking-label 0.35em
Spacing / layout: --container-max 72rem · --gutter clamp(1.25rem … 2.5rem) ·
  --section-space clamp(4.5rem … 8.5rem) · rounded-card 1.25rem · pills rounded-full
Breakpoints: Tailwind defaults, mobile-first — sm 640 · md 768 · lg 1024 · xl 1280 · 2xl 1536.
  Test widths (PLAN.md): 360 · 768 · 1024 · 1440.
Motion: --ease-soft cubic-bezier(.22,1,.36,1) (class ease-soft) · durations 200 / 450 / 700ms ·
  --reveal-distance 12px (used in Phase 5). Global prefers-reduced-motion rule disables
  animations/transitions. Hover: buttons swap fill/outline (300ms); WhatsApp lifts 2px.
Textures: texture-grain utility (SVG fractal noise data URI, 22% multiply on light, 18% on dark);
  WindowShadow (see §4). Both purely decorative, aria-hidden, no image requests.
Focus: 2px outline in the section accent color, offset 3px (:focus-visible).

7. ASSETS
==========================================================================================
Logos (public/brand, PNG, 2x) — produced by scratchpad script logos.py from brand-assets/:
  Method: inside the crop, each pixel's ink coverage a = projection of (pixel − bg) on
  (ink − bg), with the JPEG noise floor removed; then re-composited as bg' + a·(ink' − bg') using
  exact token colors. Letterforms come 100% from the source pixels (no redraw / re-typeset).
  logo-wordmark-cream.png     636x209  IMG-5 crop 196,628→832,837 · ivory on burgundy-deep
                              (official lockup, colors normalized to tokens)
  logo-wordmark-burgundy.png  636x209  same coverage · burgundy-deep ink on cream (D20 recolor)
  logo-monogram.png           594x553  IMG-3 crop 324,351→918,904 · burgundy on cream
                              (background normalized from #FEFBF3 to --cream)
  logo-monogram-cream.png     594x553  same coverage · ivory on burgundy-deep
  Each file has its background baked in → only on the matching surface (Logo component adds
  the matching bg class). next/image serves WebP/AVIF automatically.
  Recolor ink for the header = burgundy-deep, the same value as the original burgundy wordmark
  ink (#52040C measured in IMG-4).
Icons: WhatsApp and Instagram glyph paths from Simple Icons 16.35.0 (CC0), inlined as SVG.
Hand-drawn accents, window shadow and grain: drawn as SVG/CSS in this phase (no files).
Not used yet: IMG-0 Ctrl+N post, IMG-2 Sony story (approved for Phases 3–4).
