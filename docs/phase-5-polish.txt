4. SECTIONS / COMPONENTS
==========================================================================================
RevealObserver (global, root layout): queries [data-reveal] once after hydration, observes
  with rootMargin "0px 0px -8% 0px", threshold 0; marks [data-revealed] and stops observing.
  Fallback without IntersectionObserver: reveals everything immediately. Renders nothing.
reveal(index = 0, step = 90): spread onto any element → `data-reveal` and, for index > 0,
  style --reveal-delay = index × step ms.
Elements with reveal (27 on the landing page): every SectionHeading header (5), Quiénes somos
  cards (3), process steps (5) + CTA, Servicios index + 5 blocks, Equipo cards (3) + band +
  clients, Manifiesto text + image, Contacto block. Not revealed: hero, header, footer,
  WhatsApp button.
HandUnderline: hero → wipes in at 0.35s after load; others → when their block is revealed.

==========================================================================================
5. STYLES
==========================================================================================
Reveal: opacity 0 → 1 and translateY(12px → 0), 700ms (--duration-slow), --ease-soft, delay
  --reveal-delay. Only under `@media (prefers-reduced-motion: no-preference)` and `.js`.
Draw: clip-path inset(0 100% 0 0) → inset(0), 1.1s, --ease-soft, delay 0.35s.
Print: reveal elements forced visible.
Reduced motion: no hidden state, no wipe, no logo breathing, no smooth scroll (global rule).
Focus: global 2px outline in the section accent (offset 3px); WhatsApp button double ring.
Hover states (unchanged, verified): buttons swap fill/outline; nav underline grows; index
  links, footer links and email turn burgundy/ivory; Instagram pill fills; WhatsApp lifts 2px.
