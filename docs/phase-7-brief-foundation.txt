4. SECTIONS / COMPONENTS
==========================================================================================
SelectionBox({ text, after?, typing?, delay = 500, step = 85, className? })
  - Each letter is a span carrying its own slice of the yellow band → the selection widens as
    letters appear. First letter ::before = top-left handle (dot above, line down the left edge).
    Each letter ::after = bottom-right handle (line + dot below); only the current last letter
    shows it, so while typing it acts as the cursor; it blinks 3 times at the end and stays.
  - `after` (e.g. ".") sits outside the band and appears after the last letter.
  - typing=false → static selection (for "Cero improvisación" and "tu crecimiento" later).
  - Accessibility: plain text once in an sr-only span; the letter spans are aria-hidden.
    Verified: h1 accessible name = "No vendemos estética. Vendemos crecimiento."
Hero headline: 4 fixed lines — "No vendemos" / "estética." (charcoal) / "Vendemos" (dark
  burgundy) / "crecimiento" in the selection box + "." — Manrope 800,
  clamp(40px → 84px), line-height 1.05, tracking -0.035em. Rest of the hero unchanged for now.

  Text selection (::selection) = yellow + dark burgundy.
Fonts: --font-sans / --font-display = Manrope (variable 200–800); --font-label = Satoshi
  (fallback Manrope). Headlines 600–800, body 400, buttons Satoshi 700, labels Satoshi 500.
Selection box: band top 0.2em, height 1.02em; handle dot max(7px, 0.11em); line max(2px,
  0.025em). Typing: starts 500 ms after load, 85 ms per letter (~1.4 s total), only under
  prefers-reduced-motion: no-preference; otherwise the word is shown fully selected.
